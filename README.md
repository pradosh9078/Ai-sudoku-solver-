# Ai-sudoku-solver-

This repository now contains a working Android app prototype for the Sudoku solver.

## Features
- 9x9 Sudoku grid editor
- Solve button using backtracking
- Clear board button
- Load sample puzzle button

## How to run
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Select an Android emulator or device.
4. Click Run.

## Project structure
- `app/src/main/java/com/pradosh/sudokusolver/MainActivity.kt` — Android screen and input logic
- `app/src/main/java/com/pradosh/sudokusolver/SudokuSolver.kt` — Sudoku solving algorithm
- `app/src/main/res/layout/activity_main.xml` — app UI

## Notes
This version converts the original Sudoku concept into a functional Android app. It focuses on the solving engine and the user interface, rather than the original image-recognition pipeline.
